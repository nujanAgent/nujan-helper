# Changelog

## 0.1.0 (first public release, not yet published)

What the Helper offers an app that speaks ATP, such as NuJan, once you allow it:

- A Debian Linux system on the phone, set up on first start, with commands, jobs that run in the background, input
  to a command that asks a question, and limits on how long and how much each may use
- Workspaces for projects: read, write, edit, search, move and delete files, and export a workspace as a zip
- Toolchains for web, Python, native and Android builds, and the packages a project needs
- Development servers and MCP servers that keep running in the background
- Boards and serial devices over USB
- APKs a job built, offered to Android's install screen
- Shell commands in Drive this phone run at once only when they plainly just read; you are asked about any other, and those that are hard to take back every time
- Drive this phone, off until you turn it on and at your own risk: see the screen, act in other apps and use Android's shell, through
  Wireless debugging with no computer or a small Accessibility add-on, with Stop, a sign when in use, and a log of every call

On the Helper's own screens: a switch for each capability, the connected apps and what each may use, what is running
and what waits for you, a terminal, and the licences of the software it carries. A capability set to ask each time
puts each call in front of you, and the app that made the call is told while you decide, so it can move its own
bubble or panel out of the way of the question.
